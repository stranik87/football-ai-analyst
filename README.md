# Football AI Analyst

Интеллектуальная система футбольной аналитики, которая собирает статистику матчей, рассчитывает признаки, обучает модели машинного обучения и прогнозирует исход футбольного матча.

## Текущий статус

Завершены этапы:

* подготовка окружения;
* интеграция с API-Football;
* проектирование базы данных;
* импорт футбольных данных;
* модуль статистической аналитики;
* Feature Engineering;
* обучение первой модели CatBoost;
* базовое тестирование качества модели.

Текущий этап: **Этап 8 — тестирование качества модели**.

## Возможности проекта

* импорт лиг, сезонов и команд;
* импорт матчей и результатов;
* импорт статистики матчей;
* импорт турнирных таблиц;
* импорт игроков;
* анализ формы команд;
* анализ домашней и гостевой формы;
* анализ владения мячом;
* анализ передач;
* анализ ударов;
* анализ работы вратаря;
* анализ стандартных положений;
* анализ дисциплины;
* анализ атакующего и оборонительного давления;
* расчёт дней отдыха;
* построение датасета;
* обучение модели CatBoost;
* прогнозирование исхода матча:

  * `H` — победа хозяев;
  * `D` — ничья;
  * `A` — победа гостей.

## Результаты тестирования

Размер тестовой выборки: `352` матча.

Основные метрики:

| Метрика     | Результат |
| ----------- | --------: |
| Accuracy    |    0.5597 |
| Log Loss    |    0.9741 |
| Macro F1    |      0.47 |
| Weighted F1 |      0.51 |

Результаты по классам:

| Исход               | Precision | Recall |   F1 |
| ------------------- | --------: | -----: | ---: |
| Победа хозяев (`H`) |      0.57 |   0.78 | 0.66 |
| Ничья (`D`)         |      0.40 |   0.09 | 0.15 |
| Победа гостей (`A`) |      0.57 |   0.63 | 0.60 |

Главная проблема первой версии модели — низкое качество определения ничейных результатов.

Модель правильно определила:

* 116 из 148 побед хозяев;
* 8 из 88 ничьих;
* 73 из 116 побед гостей.
